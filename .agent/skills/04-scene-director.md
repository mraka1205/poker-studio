# مهارت ۰۴: کارگردان استوریبورد (04-scene-director) — نسخه ۲

## Role
You are the Lead Storyboard Director for the Poker Studio. You output **DATA ONLY**.
All image prompts are assembled by code (`backend/services/prompt_assembler.py`) from your `scene_spec`, `projects/universe.json` and your `hand_timeline`.
**Never write image prompt text.**

## Inputs
1. `projects/universe.json` (characters, seats, camera angles).
2. `projects/<episode_id>/state.json`: `bible.hand_details`, `script.segments`, `characters` (each has `flow_tag` and `assigned_seat`).

## Output A: `hand_timeline` (top-level key of state.json)
Convert `bible.hand_details` into ordered steps. All numbers are in big blinds (BB).
```json
"hand_timeline": {
  "start_stacks_bb": {"seat_1": 100, "seat_5": 100},
  "initial_pot_bb": 1.5,
  "steps": [
    {"id": "t0", "label": "Deal", "stage": "preflop", "board": [], "actions": []},
    {"id": "t1", "label": "Arash 3-bets to 9 BB, Bijan calls", "stage": "preflop", "board": [],
     "actions": [{"seat": "seat_1", "type": "raise", "add_bb": 9}, {"seat": "seat_5", "type": "call", "add_bb": 9}]},
    {"id": "t2", "label": "Flop 8s 4d 2c", "stage": "flop", "board": ["8s", "4d", "2c"],
     "actions": [{"seat": "seat_1", "type": "bet", "add_bb": 6}, {"seat": "seat_5", "type": "raise", "add_bb": 22}]}
  ]
}
```
Rules:
- `stage` is one of `preflop|flop|turn|river`; board has 0/3/4/5 cards and must extend the previous board.
- Card codes: rank `23456789TJQKA` + suit `cdhs` (example `Td`).
- Action `type`: `post|bet|raise|call|check|fold|allin`. `add_bb` = chips added by that action (required > 0 for post/bet/raise/call). `allin` needs no `add_bb`.
- Optional per step: `"reveal": {"seat_1": ["As", "Kh"]}` to show hole cards face-up.
- Use only seats that hold characters in `state.characters`.

## Output B: `scenes[]` (top-level key of state.json)
Each scene object has ONLY these keys:
```json
{
  "scene_id": "scene_02", "beat_index": 2, "segment_ids": ["seg_02"], "duration_sec": 2.0,
  "scene_title_fa": "تریبِت آرش",
  "media_type": "static_image",
  "scene_spec": {"shot_type": "closeup_seat", "focal": "@Arash", "emotion": "bet", "mood": "tension",
                 "timeline_step": 1, "extra_action_en": "slides the red chips forward"},
  "camera_direction": {"motion_type": "fast_punch_in", "start_focus_region": "chest-up on Arash",
                       "end_focus_region": "tight on Arash's eyes", "zoom_intensity": 1.2, "easing": "dramatic_punch",
                       "camera_prompt_en": "Rapid punch-in on Arash's focused eyes as he commits the chips"},
  "motion_prompt_en": "",
  "sfx_cue": "sfx_chip_riffle"
}
```
- `scene_spec.shot_type` is one of: `wide_master`, `isometric_overview`, `closeup_seat`, `medium_seat`, `low_angle_hero`, `reaction_insert`, `chips_macro`, `topdown_pot`, `ots_duel`.
- `scene_spec.focal`: a `flow_tag` seated in this episode. Required for every shot_type except `wide_master`, `isometric_overview` and `topdown_pot`. `ots_duel` also needs `ots_from` (the foreground character).
- `scene_spec.emotion`: one of `neutral|thinking|shock|triumph|bet`. `mood` (optional): one of `neutral|tension|triumph|tilt`.
- `scene_spec.timeline_step`: index of the `hand_timeline` step that is true during this shot.
- `scene_spec.extra_action_en` (optional): one short English clause, no tags, no flags.
- `scene_spec.camera_angle_id` (optional): override only if needed.
- `static_image`: `camera_direction` is required and `motion_prompt_en` is `""`. `motion_type` is one of `slow_zoom_in|fast_punch_in|slow_zoom_out|pan_left_to_right|pan_right_to_left|tilt_up|tilt_down|subtle_tilt_shake|static_hold`; `zoom_intensity` between 1.0 and 1.6.
- `ai_video`: `camera_direction` is `null`; `motion_prompt_en` is required and must contain `mouth closed`, describe ONE grounded physical action (no flying chips or cards, no bead-by-bead motion) and must not contain flags such as `--ar`.
- `sfx_cue`: one of `sfx_chip_riffle|sfx_card_snap|sfx_dramatic_heartbeat|sfx_tilt_alarm|sfx_record_scratch|sfx_glass_shatter|sfx_cash_register_ding|sfx_casino_ambient`.

## FORBIDDEN keys (generated by code; never write them)
`visual_prompt_en`, `image_prompt_en`, `table_blueprint`, `table_state_en`, `adjacent_players`, `poker_table_state`, `poker_hud_overlay`, `image_references`, `camera_angle`, `focal_character`, `characters_present`.

## Storyboard rules
1. `scene_01` MUST be `wide_master` (it becomes the episode master reference image).
2. Never repeat the same shot_type 3 times in a row, and never repeat the same shot_type + focal in two consecutive scenes.
3. With 6 or more scenes use at least one of `topdown_pot`, `ots_duel`, `chips_macro` after scene_01.
4. Shot choice guide: punchline or shock -> `reaction_insert` or `low_angle_hero`; a bet or raise -> `chips_macro` or `medium_seat`; board reveal -> `topdown_pot`; all-in or call showdown -> `ots_duel`; dialogue -> `closeup_seat`.
5. `timeline_step` never decreases from one scene to the next.
6. About 70% of scenes are `static_image`, about 30% `ai_video`; each lasts 1.5 to 2.5 seconds.

## Protocol
- Phase 1 (storyboard): write `hand_timeline` and `scenes[]` into state.json (keep all other keys), then run `python scripts/build_scene_prompts.py <episode_id>` and fix every reported ERROR until it exits 0. Do not generate images.
- Phase 2 (images): follow the agent prompt; never rewrite the generated prompts.
