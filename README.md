# استودیو کمدی و آموزش پوکر (Poker Animation Studio)
### معماری مشارکتی: Google AI Studio + Antigravity CLI + نظارت انسان (HITL)

استودیوی محلی و تحت وب برای تولید ویدیوهای انیمیشن استاپ‌موشن، کمدی و آموزشی پوکر ایرانی با مشارکت فعال انسان، مهارت‌های هدایت‌شده و عامل هوشمند بومی Antigravity.

---

## ۱. معماری سیستم و فرآیند تولید (System Architecture)

1. **مراحل خلاقانه مشارکتی (Creative Human-in-the-Loop Stages):**
   - مراحل ۱ تا ۴ و ۵ شامل **ایده و بابل (Bible)**، **سناریوی دو متنی (Subtitle / TTS)**، **کاراکترها و لنگر استایل (Characters)** و **صداگذاری**.
   - کاربر با یک کلیک روی دکمه «کپی پرامپت مهارت»، پرامپت کامپایل‌شده اختصاصی اپیزود را برای اجرا در Gemini / Google AI Studio کپی می‌کند.
   - خروجی ساختاریافته JSON در بخش ورودی مستقیم (Import JSON) ثبت شده، پس از اعتبارسنجی در `state.json` پروژه ذخیره می‌گردد.
   - **عدم تایید خودکار (HITL Strict Guardrail):** ثبت JSON به هیچ عنوان مرحله را خودکار تایید نمی‌کند؛ بررسی و تایید کیفی مرحله منحصراً با نظارت و تایید دستی کاربر صورت می‌پذیرد.

2. **کارگردانی و تصویرسازی بومی آنتی‌گرویتی (Stage 6 - Antigravity CLI Execution):**
   - مرحله ۶ (Scene Director & Frame Generation) مستقیماً توسط عامل هوشمند محلی آنتی‌گرویتی (`backend/antigravity_cli.py`) اجرا می‌شود.
   - قبل از آغاز نگارش استوری‌بورد، یک نسخه پشتیبان اتمیک از وضعیت پروژه در `state.json.pre_storyboard.bak` ذخیره می‌شود.
   - تمام خروجی‌های صحنه توسط اعتبارسنج و نرمالایزر مستقل `backend/services/scene_schema.py` اعتبارسنجی می‌شوند (محدوده کلمات ۱۲۰ الی ۴۰۰ توسط prompt_lint.py و اعتبارسنجی اسکیمای صحنه توسط scene_schema.py، تداوم بصری، وضعیت میز، دستور حرکت و نسبت ابعاد ۹:۱۶).
   - در صورت بروز هرگونه خطا یا رد اعتبارسنجی، سیستم به طور خودکار به نسخه پشتیبان قبلی بازگردانی (Rollback) می‌شود تا از مخدوش شدن اطلاعات جلوگیری شود.

## ۲. فهرست اندپوینت‌های وب‌سرویس (API Endpoints)

- **مدیریت پروژه و وضعیت:**
  - `GET/PUT/PATCH /api/projects/{id}`: دریافت وضعیت با ETag، جایگزینی کامل، یا بروزرسانی اتمیک با تشخیص تعارض (409 Conflict).
- **مهارت‌ها و پرامپت‌ها:**
  - `POST /api/projects/{id}/build-prompt/{stage}`: تولید پرامپت اختصاصی بر اساس مهارت‌های کانال.
  - `POST /api/projects/{id}/import-json/{stage}`: اعتبارسنجی و ثبت مستقیم خروجی ساختاریافته JSON.
- **وظایف پس‌زمینه Antigravity CLI:**
  - `POST /api/episodes/{id}/generate-storyboard|generate-images`: راه‌اندازی فرآیند نگارش استوری‌بورد یا تولید متوالی تصاویر فریم‌ها.
  - `POST /api/episodes/{id}/scenes/{scene_id}/regenerate-image`: بازسازی تک فریم صحنه مشخص.
  - `GET /api/episodes/{id}/task-status`: دریافت وضعیت زنده پایش وظایف پس‌زمینه و لاگ‌های ایجنت.
  - `POST /api/episodes/{id}/cancel-task`: توقف پایش و لغو وظایف در حال اجرا.

## ۳. راه‌اندازی و اجرای محلی (Setup & Execution)

### ۱) نصب وابستگی‌های پایتون:
```bash
pip install -r requirements.txt
```

### ۲) اجرای سرور بک‌اند (FastAPI):
```bash
uvicorn backend.main:app --port 8000
```

### ۳) اجرای فرانت‌اند استودیو (Vite + React):
```bash
cd frontend && npm i && npm run dev
```

### ۴) اجرای تست‌های واحد:
```bash
python -m pytest
```

## ۴. هشدار مهم امنیتی (Security Notice)

> [!WARNING]
> سرویس‌های بک‌اند (FastAPI) و فرانت‌اند (Vite Dev Server) به دلیل دسترسی مستقیم به فرآیندهای فایل‌محور و ابزارهای خط فرمان عامل هوشمند محلی، فاقد احراز هویت شبکه خارجی هستند. **این سرویس‌ها حتماً و موکداً باید تنها روی آدرس محلی `127.0.0.1` (Localhost) گوش فرا دهند و به هیچ عنوان نباید بر روی شبکه محلی (LAN) یا اینترنت عمومی در معرض دسترسی قرار گیرند.**
